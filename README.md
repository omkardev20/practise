# Full Stack Interview Prep (1–2 years experience)

Do the lessons in order. Each lesson folder has:
- `lesson.js`: read it, then run it: `node lesson.js`
- `exercises.js`: fill in the functions, then run `node exercises.js` until everything shows ✅

Don't copy answers. Type every loop yourself. Muscle memory comes back fast.

## Roadmap

### Part 1: Coding basics (most interviews start with these)
- [ ] 01 Loops: for, while, for...of, for...in, break/continue, nested loops
- [ ] 02 Arrays: map, filter, reduce, find, some/every, sort, spread
- [ ] 03 Strings: reverse, palindrome, count characters, anagram
- [ ] 04 Objects & frequency maps (the "count things" pattern)
- [ ] 05 Classic problems: two sum, remove duplicates, max/min, FizzBuzz, second largest, flatten array

### Part 2: JavaScript concepts (very commonly asked)
- [ ] 06 var vs let vs const, hoisting, scope
- [ ] 07 Closures (and the classic `setTimeout` inside a loop question)
- [ ] 08 `this`, arrow functions, call/apply/bind
- [ ] 09 Promises, async/await, the event loop (output-order questions)
- [ ] 10 Shallow vs deep copy, == vs ===, truthy/falsy
- [ ] 11 Write it yourself: debounce, throttle, Array.prototype.map polyfill

### Part 3: Frontend (React)
- [ ] 12 Components, props, state, useEffect, keys in lists
- [ ] 13 Controlled forms, lifting state up, useMemo/useCallback
- [ ] 14 Common tasks: counter, todo list, fetch and show data, search filter

### Part 4: Backend (Node + Express)
- [ ] 15 REST API basics: routes, HTTP methods, status codes
- [ ] 16 Middleware, error handling, auth (JWT vs sessions)
- [ ] 17 Build a small CRUD API

### Part 5: Databases
- [ ] 18 SQL: SELECT, WHERE, JOIN, GROUP BY, the "second highest salary" question
- [ ] 19 SQL vs NoSQL, indexes, normalization (theory questions)

### Part 6: Theory rounds
- [ ] 20 How the web works: what happens when you type a URL, CORS, cookies vs localStorage
- [ ] 21 Git basics, and how to talk about your projects
